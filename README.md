# Mystroquiry

Research site by Mystrowin, published at `research.mystrowin.com`. Built with plain HTML and CSS; no build step or runtime dependencies.

## Preview

Open `index.html` directly in a browser, or serve this folder with any static file server.

## Deployment

The public GitHub repository is [Mystrowin/research](https://github.com/Mystrowin/research). GitHub Pages publishes the `main` branch from the repository root. The custom domain is `research.mystrowin.com`, with a Cloudflare CNAME pointing to `mystrowin.github.io`. GitHub is provisioning the HTTPS certificate.

The site links to the two source records on Zenodo and the existing reproducibility repository. Both papers are identified as preprints; the first paper's measured results are bounded to its stated benchmark and configuration, and the second is described as a proposal without reported implementation or experimental results.
